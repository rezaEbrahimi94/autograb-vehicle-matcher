Find a catalogue vehicle

Enter a listing description. The matcher interprets its vehicle details and returns an ID with a confidence score.

How it works

  1. Normalize the description and identify catalogue terms.
  2. Separate the sale vehicle from equipment, donor and replacement mentions.
  3. Compare supported fields and explicit contradictions.
  4. Keep equally supported candidates; choose the one with the most listings.

Matching and SQL queries run locally. No language model or external inference API is used.

What the score means

Confidence is a heuristic from 0 to 10, not a probability. Missing or ambiguous details reduce certainty. A null ID can mean no compatible record or unresolved interpretation; read the explanation.

In the latest frozen 42-listing evaluation, 39 IDs and candidate sets were correct (92.9%): one wrong selection and two missed matches. This small, provisionally labelled sample does not establish production accuracy.
